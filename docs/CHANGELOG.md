# Changelog

## 1.2.0

- 脚本中心：支持拖拽 / 上下移动手动调整脚本顺序并持久化；脚本库列表固定高度（10 行），超出滚动
- 文件管理：移除预览设置；新增「常用路径视图」（保存当前、重命名、编辑、新增、删除）
- 文件管理：新增「下载策略视图」，可将收集范围 / 正则 / 下载方式保存为视图并一键套用
- 预览：支持关键词搜索与文本高亮（全字匹配、区分大小写、正则可配），可一键取消
- 预览：搜索结果列表在预览下方呈现，支持翻页与点击跳转对应行；新增全屏预览
- 修复：「打包并下载」现在打包完成后自动触发浏览器下载；归档路径改为绝对路径

## 1.1.0

- 精简模块：移除作业、审计、批处理页面，聚焦六大核心能力
- 执行身份：支持输入目标用户密码，通过 `su` 校验后切换执行身份（密码仅存内存）
- 脚本中心：列表内直接勾选批量执行，修复批量运行的异步懒加载报错
- 文件管理：名称正则过滤、隐藏文件开关、文本/图片预览、批量复制/打包下载到本机、批量与拖拽上传
- 进程与服务合并为一屏，支持实时自动刷新
- 导航与文案产品化改版

## 1.0.0

- 初始版本：认证、Linux 用户切换、脚本库与批量执行
- 批处理（Playbook）编排与运行历史
- 文件浏览、正则打包、目录同步
- 进程 / 资源 / systemd 服务管理
- Web 终端（PTY）与当前工作目录
- 作业中心、审计日志、系统总览
